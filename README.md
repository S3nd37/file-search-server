Локальный поисковик по текстовым файлам. Был разработан в рамках ВКР, планируется дополнить функционал.

Ищет по содержимому текстовых файлов по тем же принципам, что и обычный поисковик:
  - Поддержка стоп-слов и минус-слов в запросе;
  - Сортировка результатов по релевантности (TF-IDF);
  - Обработка ошибок доступа к файлам;
  - Сохранение индекса на диск и загрузка при повторном запуске.

Вот как это работает:
  При запуске сканируем желаемую директорию или всю систему, что пока что реализовано только на Windows.
  Базовой задачей был поиск по конкретной директории, так что этот момент я делал из интереса и на свой
  страх и риск.
  Далее вводим команду на поиск и запрос, получаем выдачу.
  Так же можно прямо в процессе менять стоп-слова, но в этом случае индекс будет сразу пересоздан, так как
  стоп-слова влияют на поиск напрямую.
  В качестве выдачи получаем пути к файлам, их id в индексе и релевантность запросу. Выдача отсортирована
  по релевантности от большей к меньшей.
