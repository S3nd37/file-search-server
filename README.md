## Локальный поисковик по текстовым файлам. Был разработан в рамках ВКР, планируется дополнить функционал.

Ищет по содержимому текстовых файлов по тем же принципам, что и обычный поисковик:
  - Поддержка стоп-слов и минус-слов в запросе;
  - Сортировка результатов по релевантности (TF-IDF);
  - Обработка ошибок доступа к файлам;
  - Сохранение индекса на диск и загрузка при повторном запуске.

Вот как это работает:
  При запуске сканируем желаемую директорию или всю систему, что пока что реализовано только на Windows.
  Базовой задачей был поиск по конкретной директории, так что этот момент я делал из интереса и на свой
  страх и риск.
  Далее вводим команду на поиск и запрос, получаем выдачу.
  Так же можно прямо в процессе менять стоп-слова, но в этом случае индекс будет сразу пересоздан, так как
  стоп-слова влияют на поиск напрямую.
  В качестве выдачи получаем пути к файлам, их id в индексе и релевантность запросу. Выдача отсортирована
  по релевантности от большей к меньшей.

## В релиз выкатил исполняемый файл, можно проверить работоспособность. ВНИМАНИЕ! Индексный файл текстовый для наглядности и создаётся рядом с исполняемым файлом, поэтому рекомендую поместить его в отдельную папку.

## Основные команды:
1)**index <путь>:** Запускает процесс сканирования указанной директории и вложенных, на основе чего строится индекс. Если путь не указан, на Windows сканируется вся система, исключая системные папки, логи, технические файлы и индексный файл программы. **Без индексации посредством этой команды никакой поиск не является возможным.** Все данные по найденным файлам хранятся в ОЗУ и сохранены в текстовом индексном файле, название которого, как и его размещение, строго закреплены в программе  - файл index с расширением .txt всегда создаётся рядом с исполняемым файлом.

2)**search <запрос>:** Выполняет поиск по всем проиндексированным документам. Поддерживает многословные запросы и исключение минус-слов. Ищет только наличие искомых слов, а сохранение последовательности слов и соответствие смысловой нагрузке игнорируется. Т.е., на данный момент найти определённое словосочетание или однокоренное слово, используя программу, не получится.

3)**setstopwords:** Даёт возможность пользователю задать свои стоп-слова после создания индекса. Те же стоп-слова будут использоваться и при повторной индексации, причём, индекс будет перестроен после выполнения команды автоматически по той же папке, так как индекс зависим от стоп-слов.

4)**help:** Выводит на экран список всех доступных команд с краткими пояснениями.

5)**exit:** Завершает работу приложения.
