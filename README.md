Этот проект представляет из себя файловую поисковую систему. Ну короче, находит файл, в котором есть введённые в запрос слова. За основу взят проект из курса практикума по C++.

Что у нас есть на данный момент:
Приложение ищет .txt файлы в заданной директории, парсит их, создаёт инвертированный индекс для возможности поиска по той же папке. Рекурсивного прохода по папкам пока нет, так 
как нужно додуматься до реализации защиты от влезания в системные папки. При парсинге текста знаки препинания и спецсимволы удаляются.

- Ядро поиска заимствовано из курса, слегка порезано, слегка доработано. Хоть я и писал этот код сам, проходя курс, но считаю что должен про это упомянуть.
- Консольный интерфейс реализован в виде REPL.
- Сохранение/загрузка индексного файла, возможность переиндексации по выбранной папке.
- Корректно работают минус-слова.
- Удобный установочный файл.
- В данный момент работаю над возможностью задания стоп-слов при запуске без наличия индексного файла и по желанию пользователя командой.



В планах:
- Рекурсивный проход по директориям для нормального поиска, а не по одной папке.
- Добавить возможность работать с русским языком.
- Возможность читать Word файлы. 
- Возможность открывать файлы из консольного интерфейса.
- Графический интерфейс.

Если желаете опробовать, после устранения основных недоработок появится установочник. А пока только код.
Рекомендую устанавливать по пути на рабочий стол, так будет легче отслеживать работу программы. 
При первом запуске создаётся тестовая директория в папке приложения.
Команды можно получить в интерфейсе, введя команду "help", как и предлагает приложение каждый раз при запуске. 
Есть скрытая команда test, тестирует на нескольких критичных на данном этапе запросах.
